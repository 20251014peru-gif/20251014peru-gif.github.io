# MACRO_STANDARD v1 — 미국·한국 매크로 감각 표준

> 상태: Draft v1 / 공식 출처 검증 및 실제 수집기 연결 전
>
> 목적: 미국·한국의 거시환경을 매일 같은 기준으로 관찰하고, 종합추론 시스템에 표준 신호로 전달한다.

---

## 1. 매크로 감각의 역할

매크로 모듈은 매수·매도 결론을 직접 내리는 프로그램이 아니다.

매크로가 답해야 할 질문:

1. 성장은 가속/둔화 중인가?
2. 물가는 가속/둔화 중인가?
3. 고용은 강화/약화 중인가?
4. 통화·유동성·금융조건은 완화/긴축 중인가?
5. 미국과 한국 중 상대적으로 어느 환경이 개선/악화 중인가?
6. 실제 시장 가격·금리·환율·수급이 이 판단을 확인하는가?

매크로 판단은 시장·뉴스·공시·유튜브 등 다른 감각과 합쳐져 최종 추론에 사용한다.

---

## 2. 화면 설계 원칙

사용자가 지표를 보고 다시 인터넷 검색하지 않아도 기본 의미를 알 수 있어야 한다.

각 지표 카드는 최소한 다음을 제공한다.

- 지표명
- 국가/그룹
- 현재값
- 기준값 또는 비교기준
- 이전값
- 시장 예상값(있는 경우)
- 방향
- 가속/둔화
- 작은 스파크라인
- 최근 수집 시각
- 데이터 대상기간
- 발표주기
- 다음 발표일(알 수 있는 경우)
- 한 줄 의미
- 투자적으로 왜 중요한지
- 공식 출처
- 공식 원자료 링크
- 상세 그래프 진입
- 데이터 상태: 정상/잠정/수정/오래됨/실패

중립값이 공식적으로 존재하지 않는 지표에는 임의의 중립값을 만들지 않는다. 대신 장기평균·이전값·컨센서스·전년동월비 등 적합한 비교기준을 사용한다.

## 3. 정보 배치

### 최상단 — 오늘 바뀐 것

모든 지표를 늘어놓지 않는다.

우선 표시:
- 오늘/최근 새로 발표된 지표
- 방향이 바뀐 지표
- 기준선/임계값을 통과한 지표
- 시장 예상과 크게 어긋난 지표
- 오래된 데이터/수집 실패

### 그룹 순서

1. 오늘의 핵심 변화
2. 성장·경기
3. 물가
4. 고용
5. 금리·통화정책·유동성
6. 한국 특화: 수출·반도체·환율·중국 영향
7. 시장 확인: 금리·FX·주식·원자재 등

각 그룹은 Core를 먼저 표시하고 Confirm/보조지표는 접을 수 있게 한다.

## 4. 공통 분류

모든 지표는 중요도와 역할을 별도로 가진다.

### Role
- `EARLY`: 선행 가능성이 높은 변화 감지
- `CORE`: 현재 매크로 판단에 핵심
- `CONFIRM`: 다른 신호 확인용
- `LAGGING`: 결과/사후확인
- `WATCH`: 아직 핵심이 아니지만 관찰

### 중요도
- `A`: 첫 화면 핵심
- `B`: 주요 보조
- `C`: 상세/확인

중요도는 유명세가 아니라 투자 추론 기여도로 정한다. 실제 성능평가 후 변경 가능하다.

## 7. 미국↔한국 상대환경

초기에는 임의 종합점수 하나로 압축하지 않는다.

같은 축으로 병렬 비교한다.

- 성장 모멘텀
- 물가 압력
- 통화정책 방향
- 금리 부담
- 유동성
- 기업/수출 모멘텀
- FX 환경
- 실제 자금흐름 확인

출력 예:

```text
미국: 성장 둔화 / 물가 상방 / 금리 부담 증가
한국: 수출 개선 / 반도체 개선 / 원화 환경 개선

현재 판정: 한국 상대환경 개선 관찰
미확인: 외국인 자금 유입 지속 여부
```

근거가 충분하지 않으면 국가 우위를 강제로 결정하지 않는다.

## 9. 스파크라인·상세 그래프

### 스파크라인
- 카드에서 최근 방향만 빠르게 인식
- 월간 지표: 기본 최근 12개 발표
- 주간 지표: 기본 최근 13주
- 일간 지표: 기본 최근 30~60 거래일 중 UI 테스트 후 결정

### 상세 그래프
- 기본 1년
- 3년 / 5년 / 최대 기간 전환
- 공식 기준선이 있으면 표시
- 발표 이벤트/수정치 구분 가능하면 보존
- 데이터 공백과 수집 실패는 선으로 연결해 숨기지 않는다.

## 10. 데이터 시간 규칙

다음 시간을 반드시 분리한다.

- `period`: 어떤 기간의 경제활동을 측정한 값인가
- `published_at`: 공식 발표 시각
- `collected_at`: 우리 시스템이 가져온 시각
- `next_release_at`: 다음 예정 발표

투자 추론에서는 `published_at` 이전에 해당 실제값을 알고 있었던 것처럼 사용하면 안 된다.

수정되는 지표는 가능하면 최초 발표값과 수정값을 분리 보존한다.

## 11. 공식 데이터 수집 원칙

우선순위:

1. 공식 API
2. 공식 데이터 다운로드/공식 페이지
3. 검증된 공공 데이터 미러
4. 상업/비공식 데이터는 공식 접근이 어려울 때만 보조

현재 공식 자동수집 후보:

### 미국
- BLS: CPI·고용·PPI·JOLTS 등
- BEA API: GDP·PCE 등
- Federal Reserve/FRED: 금리·M2·일부 금융계열
- Federal Reserve: FOMC 일정/결정

### 한국
- KOSIS OpenAPI: 물가·고용·산업활동 등
- 한국은행 ECOS: 기준금리·통화·금리·환율·생산자물가 등
- 관세청 수출입무역통계: 수출·수입·품목·국가별 무역

각 데이터의 정확한 series/table ID는 collector 구현 전에 `SOURCE_REGISTRY`에서 확정한다.

## 12. AI 독립성

이 모듈은 AI 없이 다음을 계산해야 한다.

- 현재/이전 변화
- 기준선 위/아래
- 컨센서스 대비 서프라이즈(컨센서스 데이터가 있는 경우)
- 방향
- 가속/둔화의 규칙 기반 후보
- 새 발표 감지
- 데이터 오래됨/실패
- 스파크라인
- 미국/한국 축별 병렬 비교

AI는 선택적으로 의미 설명·가설 후보·관계 설명을 보조한다.

## 13. 아직 확정하지 않는 것

실데이터 검증 전 아래를 임의로 정하지 않는다.

- 미국/한국 종합점수
- 지표별 고정 가중치
- 매수/매도 점수
- 서프라이즈 임계값
- 가속/둔화 복합점수
- 국가 우위 자동판정 임계값

이 값은 Snapshot 결과와 실제 시장 반응을 쌓은 뒤 평가한다.
