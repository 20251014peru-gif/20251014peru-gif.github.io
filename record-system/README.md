# record-system — 투자 기록·종합추론 시스템

이 폴더는 투자 기록·종합추론 시스템의 독립 작업영역이다.

## 경계 원칙

- `record-system/` 밖의 기존 프로그램은 기본적으로 읽기 전용으로 취급한다.
- 뉴스레이더·유튜브·공시·기존 매크로 관측실 등은 독립 프로그램으로 유지한다.
- 필요한 데이터는 Adapter를 통해 가져온다.
- 신규 종합추론 관련 코드·표준·테스트·UI는 이 폴더 안에 만든다.
- 기존 배포 파일의 이동·삭제는 의존성 확인 전 하지 않는다.
- AI는 선택 기능이다. AI가 없어도 핵심 데이터 수집·계산·판단은 동작해야 한다.

## 구조

```text
record-system/
├─ standards/          공통 신호·출처·평가 표준
├─ senses/             감각기관 연결부
│  ├─ macro/           미국·한국 매크로
│  ├─ market/          가격·수급·자금흐름
│  ├─ news/            뉴스 Adapter
│  ├─ youtube/         유튜브 Adapter
│  └─ filings/         공시 Adapter
├─ reasoning/          종합추론 엔진
├─ capital-flow/       자본흐름 지도
├─ records/            사건·가설·Snapshot 기록
├─ evaluation/         정확도·선행성·오신호 평가
├─ ui/                 종합추론 화면
└─ tests/              회귀·통합·실시간 실험
```
