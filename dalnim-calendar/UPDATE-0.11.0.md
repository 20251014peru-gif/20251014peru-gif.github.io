# 0.11.0 — 나중에 다시 알림

투자 기록·확인 예정·재검토 창 아래에 **나중에 다시 알림**을 추가했습니다.

- 1·3·6·24시간 뒤 예약 또는 날짜와 5분 다이얼로 직접 지정.
- 같은 항목은 하나의 예약을 유지하며 재선택 시 시간을 변경.
- 예약 시간 표시와 예약 취소. 이 창에서 확인 완료 처리할 때 해당 재알림 취소.
- 기존 투자 원문의 날짜·본문은 유지. 개인 캘린더에 별도 다시 확인 항목을 저장.
- 알림을 눌러 열거나 해당 달력 항목을 선택하면 원래 확인 창을 복원.
- 서버 응답을 받은 뒤 예약을 확정하며 오프라인 실패를 완료로 표시하지 않음.
- 등록된 수신 기기 유무와 알림 설정 버튼 제공. 체험 공간은 실제 푸시를 발송하지 않음.

기존 이벤트 API와 매분 실행하는 calendarReminderSweep를 재사용하므로 새로운 서버 배포는 필요하지 않습니다. 브라우저·PC가 꺼져 있어도 서버가 처리하며, 실제 휴대폰 표시는 기기 연결·알림 권한·네트워크 상태의 영향을 받습니다. 이 변경에서 실제 휴대폰 수신을 검증하지는 않았습니다.

별도 투자 요약 알림 시간은 그대로입니다. 투자 기록보관실에서 직접 완료하는 동작과 재알림 취소의 자동 연동은 이번 범위가 아닙니다.

검증: 자동 테스트 78개 통과. 기존 서버 정제·예약 함수와 결합해 지정 시각·원문 보존·ID 재사용·취소·재예약·인터넷 실패를 확인했습니다. PC/390px 휴대폰 브라우저에서 예약·새로고침·재열기·시간 변경·취소·과거 시각 거부 및 5분 다이얼을 검수했습니다. 실제 계정 데이터를 수정하거나 테스트 푸시를 보내지는 않았습니다.
