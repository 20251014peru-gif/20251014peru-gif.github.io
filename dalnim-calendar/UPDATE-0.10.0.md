# 0.10.0 — 개인 투자·기록 전용 구조

가족·업무를 함께 다루던 화면을 **투자 노트 + 나의 기록**으로 정리했습니다.

## 변경

- 가족 초대·공유 선택과 업무일지 연결·워크로그 JSON 가져오기 메뉴를 제거했습니다.
- 나의 기록 입력은 메모·관찰·학습·복기와 주제로 구성합니다. 투자 입력과 사진·체크리스트는 유지합니다.
- 신규·수정 기록은 개인 공개 범위로 저장합니다. 진행 상태 완료 기본값, 5분 다이얼과 하루 흐름 위젯은 유지합니다.
- 업무일지 버튼 대신 실제 투자 기록보관실로 이동합니다.
- 데이터 연결은 투자 읽기 모듈 하나로 정리했습니다. 연결을 꺼도 직접 쓴 투자 노트의 입력·저장은 계속 가능합니다.
- 투자 가져오기의 빈 결과·오류·갱신 중·마지막 성공 시간을 구분합니다. 화면이 보이는 동안 60초 간격으로 갱신합니다. 늦게 도착한 이전 연결 응답을 무시하고 계정 저장소 변경 시 이전 결과를 제거합니다.
- 이전 가족·업무 기록은 삭제하지 않습니다. 현재 달력·모아보기·알림함에서 제외하고 설정의 읽기 전용 보관 화면 및 전체 백업에서 보존합니다.

## 데이터와 배포 범위

기존 Firestore 공간 ID와 데이터 경로를 그대로 사용합니다. 과거 기록의 내용·상세·공유 설정·분류 설정을 일괄 덮어쓰지 않습니다. 현재 배포는 웹 프런트엔드만 변경합니다. 서버 함수·멤버십·초대 토큰·기존 알림 예약을 수정하거나 폐기하지 않습니다. 구버전 클라이언트의 호환 코드도 유지합니다.

투자 원문은 기록보관실에서 수정합니다. 원문 전체 양방향 편집, 실제 휴대폰 수신 검증은 이번 변경에 포함하지 않습니다.

## 검증

- Node 자동 테스트 71개 통과: 분류 보존, 이전 기록 식별, 백업 제한, 선택 연결 실패·해제·늦은 응답·계정 변경 회귀 포함.
- 로컬 브라우저에서 나의 기록 저장 후 새로고침·재열기 확인.
- 합성한 이전 업무 기록이 활성 달력에서 빠지고 보관 화면에 내용·상세가 유지되는지 확인.
- 투자 연결 해제 후 투자 상세 입력 유지 확인.
- PC 및 휴대폰 폭에서 모달·데이터 연결·달력 화면 확인. 가로 넘침 없음.
- 실제 서버 데이터 수정·삭제 및 푸시 발송은 검증 과정에서 수행하지 않음.
