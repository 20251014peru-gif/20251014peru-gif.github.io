# 달님 실사용 안내

접속 주소: https://20251014peru-gif.github.io/dalnim-calendar/

1. **내 캘린더 열기 → Google 계정으로 계속**을 누릅니다. 기존 Firebase에 등록된 본인 계정을 사용합니다.
2. **새 일정**을 만들어 저장합니다. 화면에 **클라우드 연결됨**이 표시되는지 확인합니다.
3. 휴대폰에서도 같은 주소와 계정으로 엽니다. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.
4. **알림함 → 이 기기 연결 → 테스트 알림** 순서로 눌러 실제 수신을 확인합니다.
5. 2~3분 뒤 일정에 알림을 설정한 다음 컴퓨터를 끄고 휴대폰 수신을 확인합니다.

일정은 Firebase Firestore에 저장되고 서버가 예약 알림을 처리합니다. 컴퓨터를 끄거나 웹 화면을 닫아도 서버는 계속 동작합니다. 휴대폰 인터넷 연결, 브라우저·앱 알림 권한, 절전 제한은 별도로 확인해야 합니다.

알림 기록의 **서비스 접수**는 발송 서비스가 요청을 받았다는 의미입니다. 휴대폰에 표시되었다는 보장은 아닙니다. 알림을 눌러 로그인한 앱에서 열면 열기 확인을 기록합니다.

초기 사용자는 본인 계정 한 명입니다. 가족은 계정을 등록하고 해당 공간의 구성원 권한을 부여한 후 사용할 수 있습니다.

기존 운영 워크로그와의 자동 양방향 연동은 아직 활성화되지 않았습니다. JSON 가져오기는 원본의 복사이며, 이후 원본 수정이 자동 반영되지는 않습니다. 연결 블록의 별도 로컬 체험 화면도 운영 서버 데이터와 구분됩니다.

클라우드 모드는 인터넷 연결이 필요합니다. 서버 연결이 실패했을 때 로컬에 저장한 것처럼 표시하지 않습니다. 중요한 기록은 설정에서 JSON 백업을 내보낼 수 있습니다.
