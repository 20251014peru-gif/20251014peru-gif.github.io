# 달님 캘린더 사용 안내

접속 주소: https://20251014peru-gif.github.io/dalnim-calendar/

1. **내 캘린더 열기 → Google 계정으로 계속**을 눌러 기존 본인 계정으로 로그인합니다.
2. **새 기록**에서 **나의 기록** 또는 **투자 노트**를 선택하고 저장합니다. 새 기록은 나만 보기·완료가 기본입니다.
3. **기록보관실** 버튼으로 투자 원문을 엽니다. **데이터 연결**에서 투자 기록 가져오기를 켜거나 끄고 연결 상태를 확인합니다.
4. 휴대폰에서도 같은 주소와 계정을 사용합니다. 브라우저 메뉴의 홈 화면에 추가로 설치할 수 있습니다.
5. 알림이 필요하면 **알림함 → 이 기기 연결 → 테스트 알림**으로 수신을 확인한 뒤, 기록의 상태를 **예정**으로 바꾸고 미래 시간과 알림을 설정합니다. 완료된 기록은 알림을 보내지 않습니다.

클라우드 기록은 Firebase Firestore에 저장되고 예약 알림은 서버가 처리합니다. 컴퓨터를 꺼도 서버는 동작합니다. 실제 휴대폰 표시는 인터넷 연결·알림 권한·기기 설정에 영향을 받습니다. 서비스 접수 표시는 실제 표시 보장이 아니므로 휴대폰 수신을 직접 확인하세요.

개인 투자·기록 용도로 사용합니다. 가족 초대와 업무일지 연결 메뉴는 없습니다. 기존 가족·업무 기록이 있으면 **설정 → 이전 분류 기록**에서 확인할 수 있습니다. **전체 기록 백업**에는 이전 분류와 삭제된 기록도 포함됩니다. 캘린더 백업 JSON만 가져올 수 있습니다.

투자 연결을 꺼도 직접 작성한 투자 노트와 나의 기록은 유지됩니다. 연결에 문제가 있으면 오류로 표시하며, 같은 계정에서 마지막으로 읽은 기록이 있으면 보관해 보여 줍니다. 가져온 원문은 기록보관실에서 수정합니다.

시간 버튼은 5분 간격 다이얼입니다. 하루 흐름은 마우스를 올리거나 버튼을 눌러 확인합니다. 기존 기록은 자동으로 삭제하거나 새 공간으로 옮기지 않습니다.
