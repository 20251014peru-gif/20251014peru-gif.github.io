# 0.12.1 · 확인 방식별 캘린더

투자 노트에 모여 있던 연결 항목을 지표·자료 확인, 유튜브 결과 확인, 예측 검증, 투자 기록으로 나눠 표시한다. 직접 작성한 나의 기록과 사용자 분류도 유지한다.

- 위쪽 버튼은 캘린더 하나만 보기, 전체는 모두 보기. 왼쪽 체크는 여러 캘린더를 조합한다. 완료 숨김은 선택 사항이며 기본은 기존처럼 전체 상태를 보여준다. 보기 선택은 현재 브라우저에 저장된다.
- 자료 확인은 블루, 영상 후속 확인은 로즈, 예측 검증은 라벤더. 같은 항목의 색이 순서나 날짜에 따라 바뀌지 않는다.
- 유튜브 결과 확인은 원본 질문 앞의 `📺 영상`, `📺 유튜브`, `🔄 직전`, `🔁 직전` 표시를 기준으로 한다. 본문에 유튜브라는 말이 있거나 원본이 영상이라는 이유만으로 분류하지 않는다. 명시된 영상 표시가 없는 확인·복기는 지표·자료 확인에 표시한다. 예측 대장 항목은 별도의 예측 검증에 표시한다.
- 재알림은 해당 원본과 같은 캘린더에 표시한다. 원본을 불러올 수 없으면 예약 당시 보존된 제목·종류를 이용한다.
- 월·연 보기의 요일 머리글에 무관한 날짜 숫자가 붙던 표시도 정리했다.

이 변경은 화면 분류만 적용한다. 원본 ID/분류, 편집·완료 저장, 기존 알림 예약은 바꾸지 않는다. 화면에서 숨기는 것은 알림 취소가 아니다. 서버나 데이터 이전 없이 웹만 배포한다.
