# 0.6.0 업데이트

체크박스가 "메모 텍스트 속 마크다운 표시"였던 0.5.x의 방식을 걷어내고, **체크리스트를 정식 데이터 항목으로** 새로 만들었습니다.

## 무엇이 바뀌었나

- **메모**: 이제 순수한 자유 텍스트입니다. 체크박스·목록 버튼이 없습니다.
- **체크리스트**: 메모 아래 별도 섹션입니다. "+ 항목 추가"를 누르면 실제 `<input type="checkbox">`와 텍스트 입력칸이 한 줄에 나란히 생기고, 오른쪽 × 버튼으로 그 항목만 삭제할 수 있습니다.
- 이전 버전에서 "체크박스가 메모 밑에 따로 나온다"고 하신 문제의 근본 원인은 체크박스가 메모 텍스트를 흉내 낸 것이었기 때문입니다 — 이번에는 아예 별도의 정식 항목이라 그런 문제 자체가 없습니다.

## 데이터 구조 변경 (내부)

- 일정 데이터에 `checklist` 필드가 추가됐습니다: `[{text, done}]` 배열, 항목당 최대 200자, 일정당 최대 50개.
- 서버(`server/policy.mjs`)도 저장할 때 같은 방식으로 검증합니다 — 그래서 **이번엔 Firebase 함수 재배포가 필요합니다.**
- 기존 일정의 `notes`(메모)에 이전에 "- [ ] "로 넣어두신 내용이 있다면, 그 텍스트는 그대로 메모에 남아있고 자동으로 체크리스트로 옮겨지지 않습니다. 필요하면 새 체크리스트 항목으로 다시 추가해 주세요.

## 검증

- 로컬 유닛 테스트: `sanitizeChecklist`(빈 항목 제거, 길이·개수 제한), `cleanEvent`(서버 저장 시 체크리스트 검증) 포함 51개 통과.
- 로컬 미리보기에서 직접 확인: 항목 추가 → 한글 입력 → 체크 → 저장 → 다시 열기까지 전 과정을 실제로 수행해 정상 동작을 확인했습니다.
- **미검증**: 실제 클라우드 계정으로 저장했을 때(재배포 후) 서버가 체크리스트를 올바르게 저장·반환하는지는 재배포 후 확인이 필요합니다.

## 재배포 필요

이번엔 `server/policy.mjs`가 바뀌어서 프런트엔드만 새로고침해서는 부족합니다:

    git pull origin main
    cd dalnim-calendar
    pnpm install --frozen-lockfile
    pnpm test
    firebase deploy --only functions:dalnim-calendar --project my-system-25497
