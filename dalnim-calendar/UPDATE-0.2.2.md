# 0.2.2 화면 업데이트

- 시작·종료 시간: 오전/오후 시계 다이얼, 분 선택 5분 간격. 취소하면 기존 시간이 유지됩니다. 기존 비정각 시간은 편집하지 않으면 보존됩니다.
- 캘린더 드래그와 시간 선택도 5분 간격으로 맞춥니다. 화면의 시간 눈금은 읽기 편한 30분 간격입니다.
- 하루의 흐름: 고정 열을 없애고 마우스 올리기 / 터치 / 키보드로 여는 위젯으로 전환합니다.
- 새 일정의 기본 진행 상태는 완료입니다. 기존 일정 상태는 유지합니다. 완료 상태는 알림 대상이 아님을 편집창에서 안내합니다.
- 업무일지 버튼은 기존 ../worklog.html로 이동합니다.
- 워크로그 입력: 일반업무 / 외주·비용 탭, 층·분야·대상년도·대상월·담당자·지출종류·금액·업체 연락처·견적 메모·자재명·수량. 탭 전환 중 내용은 유지됩니다.

## 연동 범위

업무일지의 주요 필드 이름과 탭 구성을 맞춘 캘린더 편집 화면입니다. 기존 업무일지의 모든 기능을 복제한 것은 아닙니다. 자동완성·업체/분야 관리·다중 자재 재고 출고·첨부 업로드·보류 상태 등은 기존 업무일지에서 사용합니다.

추가 상세 필드는 캘린더 이벤트의 details에 저장합니다. 연결 기록의 기존 사진·첨부·사용자 정의 필드는 기존 계약을 통해 보존합니다. 기존 업무일지의 worklog_entries와의 자동 동기화는 활성화하지 않습니다. 같은 화면으로 보이는 것만으로 양방향 동기화가 되는 것은 아닙니다. 서버 배포나 기존 업무일지 코드는 변경하지 않습니다.
