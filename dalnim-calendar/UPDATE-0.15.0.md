# 0.15.0 예측 검증 상세 입력

유튜브 예측은 확인·복기와 달리 검증 기한, 판정, 근거만 표시하던 분기였다. 이제 같은 전체 화면 3열 컴포넌트에서 원본 발언·기준선·반증 조건, 확인 지침, 근거 링크, 비교, 관찰 변화, 판단 이유, 교훈과 다음 행동을 기록한다. 예측 판정은 대기중/적중/빗나감/판정불가를 그대로 사용한다. 확인 지침과 판단 입력은 처음부터 펼친다. 0.14.1 보관실 공통 편집기 연결도 유지한다.

기존 youtube_predictions 문서의 검증기한/상태/판정근거를 계속 공유한다. 추가 검증 항목은 같은 문서의 calendarVerification에 저장하며 기존 3필드 클라이언트 수정 시 보존한다. 원문 발언과 원래 기준을 덮어쓰지 않는다. integrationHistory에는 전후 상세 스냅샷을 남긴다. 저장, 이력, 예약 알림 취소는 하나의 트랜잭션으로 처리한다. fingerprint 충돌 검사와 중복 저장 방지 유지. 추가 API 권한이나 Firestore 규칙 변경 없음. 읽기 전용 자동 채점 항목은 원본 프로그램에서 관리한다.

상세 API가 지원되는 서버부터 배포한 뒤 화면을 배포한다. 서버 기능 표시가 없으면 신규 상세 저장을 막아 조용한 데이터 누락을 방지한다. 배포 자체로 투자 기록을 변경하거나 이관하지 않는다.

검증: 120개 Node 테스트. 상세 저장/재열기, 원본 3필드와 추가 필드 보존, 외부 수정 충돌, 재시도 이력 1회, 트랜잭션 실패, 잘못된 날짜·URL, 판정 및 근거가 있는 같은 패턴 사례, 선택적 조회 실패, 원문 HTML 이스케이프. 격리 브라우저에서 발췌 복사·상세 입력·저장·재열기와 저장 이력 표시 확인. 실제 계정 데이터 저장은 시험에 사용하지 않는다.
