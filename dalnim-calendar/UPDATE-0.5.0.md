# 0.5.0 업데이트

편집 창을 "공통 필드 먼저, 카테고리는 덧붙이는 것" 구조에서 "카테고리마다 전용 화면" 구조로 바꿨습니다.

## 모달 순서가 바뀌었습니다

제목 → **종일·시작·종료·반복·미리 알림** → 캘린더·진행 상태 → **카테고리 전용 화면** → 메모 → 공개 범위. 언제(시작·종료)가 가장 먼저 보이고, 카테고리를 고르면 그 카테고리의 전용 화면이 날짜보다 아래, 메모보다 위에 바로 나타납니다.

## 나의 일정도 전용 화면이 생겼습니다

- **종류**: 일정 / 할 일 / 약속 중에서 고릅니다. "업무"는 옵션에 없습니다 — 업무는 워크로그 카테고리에서만 다룹니다.
- **주소 / 전화번호**를 각각 따로 입력합니다. 주소는 "네이버 지도에서 보기", 전화번호는 "전화 걸기" 링크가 자동으로 뜹니다. (0.4.1에서 하나로 합쳐뒀던 "장소" 필드는 없앴습니다 — 주소와 전화번호를 구분할 수 없어 불편하다는 의견을 반영했습니다.)

## 가족 일정이 가벼워졌습니다

- 이동수단·숙소 항목을 없앴습니다.
- 진행 상태(예정/진행 중/완료) 선택을 숨겼습니다 — 가족 일정에는 큰 의미가 없다는 판단입니다.
- 목적지 대신 나의 일정과 같은 방식으로 **주소·전화번호를 분리**했습니다(숙소 예약처 전화, 모임 장소 주소 등에 바로 쓸 수 있게).
- 종류(일반/여행/행사/모임)와 함께하는 사람, 준비할 것은 그대로입니다.

## 투자 노트는 장소·전화번호 없이 유지

투자 노트에는 원래도 주소·전화번호 개념이 없었고, 이번에도 추가하지 않았습니다(요청하신 대로입니다).

## 메모에 체크박스·목록 버튼

메모 위에 "체크박스"와 "목록" 버튼 두 개를 추가했습니다. 누르면 커서 위치에 `- [ ] `(체크박스) 또는 `- `(목록) 표시가 줄 단위로 삽입됩니다.

**참고로 잡은 화면(굵게·기울임·밑줄·번호목록·글머리·링크 6개 버튼짜리 서식 도구모음)은 그대로 넣지 않았습니다.** 그 형태로 만들려면 메모를 일반 텍스트가 아니라 HTML로 저장해야 하는데, 그러면 저장·검색·백업(JSON 내보내기)·다른 프로그램에서 이 데이터를 읽는 모든 곳에서 안전하게 이스케이프 처리를 다시 해야 합니다(잘못하면 스크립트 삽입 같은 보안 문제로 이어질 수 있습니다). 말씀하신 "체크박스, 글머리 기호만"이라는 요청과도 맞아서, 이번에는 일반 텍스트에 마크다운처럼 표시만 삽입하는 가벼운 방식으로 만들었습니다. 노션·삼성·구글 캘린더 수준의 진짜 서식 편집기가 필요하시면 별도로 설계가 필요합니다(말씀해 주세요).

## 사진 첨부 — 아직 아님

투자 노트, 가족 일정 모두 "사진 첨부"는 넣지 않았습니다. 이 앱은 지금 사진을 저장할 공간(Firebase Storage)에 연결되어 있지 않아서, 사진 첨부를 하려면:

1. Firebase Storage 연결(비용 발생 가능),
2. 업로드·미리보기·삭제 UI,
3. 보안 규칙(본인 사진만 읽고 쓸 수 있게)

이 세 가지를 새로 만들어야 합니다. 복잡해서 못 하는 게 아니라, 별도로 계획하고 진행하는 게 안전하다고 판단해 이번 범위에서는 뺐습니다.

## 검증

- 전체 유닛 테스트 48개 통과(이번 변경은 화면 쪽이라 새 테스트는 추가하지 않았습니다 — 기존 테스트가 다루는 도메인 로직은 건드리지 않았습니다).
- **미검증**: 실제 화면에서 각 카테고리 전용 입력이 올바르게 나오는지, 가족 일정에서 진행상태가 실제로 숨겨지는지, 메모 버튼이 실제 텍스트 삽입을 제대로 하는지는 아직 실기기로 확인하지 않았습니다.
- 서버 코드는 건드리지 않았습니다 — Firebase 재배포 불필요, GitHub Pages 새로고침만 하면 됩니다.
