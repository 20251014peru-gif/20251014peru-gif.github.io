# 0.7.0 업데이트

일정에 **사진을 첨부**할 수 있습니다. 나의 일정·투자 노트·가족 일정에서 쓸 수 있고, 워크로그는 제외했습니다(업무일지 모달을 그대로 씁니다).

## 무엇이 바뀌었나

- 메모 아래 "사진" 섹션이 생겼습니다. "+ 사진 추가"로 여러 장을 한 번에 고를 수 있고(최대 8장), 썸네일을 누르면 사진 보기 화면이 뜹니다.
- 사진 보기 화면: 휠·핀치·더블클릭으로 확대·축소, 드래그로 이동, 여러 장이면 좌우 화살표로 이동, **저장**(다운로드)과 **공유**(휴대폰 공유 시트) 버튼을 제공합니다.
- 사진은 **일정을 먼저 저장한 뒤에만** 추가할 수 있습니다. 새 일정을 만드는 중이라면 "일정을 저장한 뒤 사진을 추가할 수 있어요" 안내가 뜨고, 저장 후 다시 열면 추가할 수 있습니다. (체험 공간에서는 이 제한이 없습니다 — 아래 참고.)
- 사진 추가·삭제는 저장 버튼과 별개로 즉시 반영됩니다(다른 항목처럼 저장하기를 눌러야 반영되는 게 아닙니다).

## 어디에 저장되나 (클라우드 계정)

- 사진 원본은 이미 다른 앱(사진/영수증 스캔 앱)이 쓰고 있는 **같은 Firebase Storage 버킷**(`my-system-25497.appspot.com`)에 업로드됩니다 — 새 서비스나 새 요금 구조를 만들지 않았습니다.
- 저장 경로는 `dalnimPhotos/공간ID/일정ID/사진ID`로, 다른 공간·다른 일정의 사진과 섞이지 않습니다.
- 업로드·삭제는 반드시 서버(Cloud Functions)를 거칩니다: 로그인 확인 + "이 일정을 수정할 수 있는 사람인지"(소유자 또는 가족 공유 편집자) 확인을 통과해야 합니다. 브라우저에서 Storage에 직접 쓰지 않습니다.
- 사진 1장 최대 6MB(업로드 전 휴대폰에서 자동으로 1600px·JPEG로 압축), 일정 하나에 최대 8장까지 — 무제한 업로드로 비용이 새는 것을 막았습니다.
- 체험 공간(로그인하지 않은 데모 모드)에서는 사진이 이 기기의 IndexedDB에만 저장됩니다. 클라우드에는 올라가지 않고, 기기를 바꾸면 보이지 않습니다.

## 데이터 구조 변경 (내부)

- 일정 데이터에 `photos` 필드가 추가됐습니다: `[{id, url, createdAt}]`, 최대 8개.
- 서버(`server/policy.mjs`, `server/index.mjs`)에도 같은 검증이 들어갔고, 사진 업로드·삭제를 처리하는 새 경로(`/events/:id/photos`)가 생겼습니다 — **이번엔 Firebase 함수 재배포가 필요합니다.**

## 검증

- 로컬 유닛 테스트: `sanitizePhotos`(허용된 주소만 통과, 개수·용량 제한), 서버 저장 시 검증(`cleanEvent`), Storage 경로·다운로드 주소 생성 헬퍼 포함 59개 통과.
- 로컬 미리보기(체험 공간)에서 직접 확인: 사진 추가 → 갤러리 표시 → 사진 보기(확대·이동·좌우 이동) → 닫기 → 삭제 → 저장 → 다시 열어 반영 확인, 워크로그로 분류를 바꾸면 사진 섹션이 숨는 것까지 실제 브라우저에서 수행해 확인했습니다.
- **미검증 (재배포 후 실제 기기 확인 필요)**:
  - 실제 클라우드 계정에서 사진 업로드가 Storage에 정상적으로 쓰이는지, Cloud Functions 서비스 계정에 이 버킷 쓰기 권한이 있는지.
  - 휴대폰에서 "저장"이 실제로 파일로 저장되는지(브라우저마다 동작이 다를 수 있어 새 탭으로 열리며 길게 눌러 저장하는 방식으로 대체될 수 있습니다).
  - 휴대폰에서 "공유"가 카카오톡 등 실제 앱으로 사진 파일이 정상적으로 전달되는지.
  - 가족 공유 일정에서 다른 가족 구성원이 사진을 보고, 편집자 권한이 있다면 추가·삭제까지 할 수 있는지.

## 재배포 필요

`server/index.mjs`, `server/policy.mjs`, `src/core/model.js`가 바뀌어서 프런트엔드만 새로고침해서는 부족합니다:

    git pull origin main
    cd dalnim-calendar
    pnpm install --frozen-lockfile
    pnpm test
    firebase deploy --only functions:dalnim-calendar --project my-system-25497
