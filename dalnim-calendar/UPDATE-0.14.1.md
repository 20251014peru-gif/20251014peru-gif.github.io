# 0.14.1 확인·복기 공통 화면

수정 시각: 2026-09-28 13:02 KST. 실제 공통 컴포넌트와 서버 저장 계약을 사용한 격리 브라우저 시험 통과: 저장·재열기·왕복 링크·동시 수정 충돌·실패 시 입력 보존·사진/추가 필드 보존·390px 화면. 실제 개인 계정 왕복 저장과 알림 발송은 미검증.

보관실 7.40.0은 이 앱의 investment-detail.js/verification-panel.js와 스타일을 직접 불러오며 같은 calendarApi 상세/저장/알림 경로를 사용한다. UI 복제본이나 새 확인 컬렉션 없음. 동일 followup ID의 질문/결과/확인 지침/패턴/이력을 공유한다. 기존 원본 링크는 유지하고 보관실의 #followup=ID로 왕복하는 링크를 추가. 기존 ?investment=investment-followup:ID 경로는 그대로 사용한다.

보관실 로그인 토큰은 서버 Authorization에만 사용, URL/저장소/메시지에 복사하지 않는다. 보관실에서 새 질문 작성 후 저장하면 공통 화면을 연다. 기존 사진/질문 수정은 추가 정보 경로에 남긴다. 충돌 검사는 기존 서버 revision과 저장 이력 계약을 그대로 재사용한다. 독립 연결 실패는 저장 성공으로 표시하지 않는다. 서버/개인 데이터 이관 없음. 코드 복구는 직전 소스 재배포, 저장 자료는 삭제하지 않는다. 격리 검증과 실제 개인 계정 시험을 구분한다.

최신 0.14.0의 전체 화면 확인 작업창·관련 원문 문장 보기·verification.css를 보존하고 공통 프레임에서도 같은 스타일을 사용한다.
