# 달님 캘린더 0.11.0

혼자 사용하는 투자·개인 기록 캘린더입니다. 투자 기록보관실의 날짜 있는 기록과 직접 남긴 메모·관찰·학습·복기를 한곳에서 봅니다.

실사용 주소: https://20251014peru-gif.github.io/dalnim-calendar/

본인 계정으로 로그인하면 기존 Firebase Firestore에 저장합니다. 시작 순서는 [START-HERE.md](START-HERE.md), 이번 변경 범위는 [UPDATE-0.10.0.md](UPDATE-0.10.0.md)를 참고하세요.

0.10.1: 달력 상단과 로그인 전 화면에 **6대축 홈** 바로가기를 추가했습니다. PC·휴대폰 모두 나의 시스템 인생 6대축 홈으로 이동하며, 홈 주소는 `src/config.js`의 `systemHomeUrl`에서 관리합니다.

0.11.0: 투자 확인 창에 **나중에 다시 알림**을 추가했습니다. 1·3·6·24시간 후 또는 날짜·5분 다이얼로 지정합니다. 원문 날짜는 유지하고 기존 서버 알림으로 예약하며, 같은 항목의 재예약은 시간을 변경합니다. 자세한 범위는 [UPDATE-0.11.0.md](UPDATE-0.11.0.md)를 참고하세요.

## 현재 구성

- **투자 노트**: 종목·주제, 시장, 참고 링크, 확인할 내용을 기록합니다.
- **나의 기록**: 메모·관찰·학습·복기에 사진과 체크리스트를 함께 보관합니다.
- **데이터 연결**: 투자 기록보관실의 기록·확인 예정·공부노트 재검토를 가져옵니다. 가져온 원문 수정은 기록보관실에서 합니다.
- 가족 초대·공유 선택, 업무일지 버튼·입력 블록·워크로그 JSON 가져오기는 현재 화면에서 제외했습니다.
- 이전 가족·업무 기록은 삭제하지 않습니다. 설정 → 이전 분류 기록에서 읽을 수 있고 전체 JSON 백업에도 포함됩니다.

일간·주간·월간·연간·목록 보기, 검색, 반복, 5분 시간 다이얼, 하루 흐름 위젯, 사진·체크리스트, 휴지통·백업·인쇄는 유지합니다. 새 기록의 상태는 완료이며 나만 보는 기록으로 저장합니다. 알림이 필요하면 상태를 예정으로 바꿉니다.

투자 데이터 연결은 선택 기능입니다. 연결을 끄거나 가져오기가 실패해도 직접 쓴 기록을 삭제하지 않습니다. 60초마다 화면이 보이는 동안 갱신하고, 마지막 갱신·빈 결과·연결 오류를 구분해서 표시합니다. 가져오기 실패 시 같은 계정에서 마지막으로 받은 기록은 유지하지만 최신 상태로 표시하지 않습니다.

## 저장과 보존

실사용 서버의 기존 공간 ID는 데이터 유지를 위해 그대로 사용합니다. 코드의 `workspaceId: 'family'`는 기존 저장 경로 이름이며 현재 화면에서 가족 기능을 사용한다는 뜻이 아닙니다. 이번 버전은 기존 공간 구성원·서버 권한을 일괄 변경하거나 과거 기록을 다른 저장 경로로 옮기지 않습니다.

직접 생성·수정하는 기록은 `visibility: 'personal'`로 저장합니다. 기존 기록의 공유 값·상세·첨부를 일괄 수정하지 않습니다. 기존 업무 프로그램과 자동 양방향 연결은 사용하지 않습니다. 과거 연결 어댑터·서버 경로는 이전 데이터와 클라이언트 호환을 위해 소스에 보존합니다.

서버에 연결할 수 없을 때 체험 저장소로 자동 전환하지 않습니다. 로컬 체험은 IndexedDB에만 저장하고 실제 푸시를 보내지 않습니다. 중요한 기록은 설정에서 전체 백업을 내보내세요.

## 실행과 테스트

Node.js 22 이상에서:

    npm start

실사용 설정은 기존 클라우드 API를 가리킵니다. 로컬 체험은 복사본의 `src/config.js`에서 `apiBase`를 빈 문자열로 바꾸고 `http://127.0.0.1:4173`을 엽니다. 프런트엔드 미리보기에는 패키지 설치가 필요하지 않습니다. `file://`로 직접 열지는 않습니다.

의존성 설치 후:

    npm test

0.11.0 검증: 자동 테스트 78개 통과. 다시 알림의 서버 계약·중복 방지·취소·오프라인 실패를 포함합니다. 로컬 브라우저에서 다시 알림 예약·변경·취소, 새로고침 후 확인 창 재열기, 과거 시각 거부, PC·모바일 배치와 5분 다이얼을 확인했습니다. 실제 계정의 데이터 수정 및 휴대폰 수신 검증은 이 업데이트에서 수행하지 않았습니다.

## 알림과 서비스 범위

클라우드 API와 예약 알림 서버는 컴퓨터 전원과 관계없이 동작합니다. 휴대폰에서 알림 권한·기기 등록·실제 테스트 수신을 확인해야 합니다. 발송 서비스 접수는 휴대폰 표시 보장이 아닙니다. SMS 대체 발송은 구현하지 않았습니다.

이 업데이트는 프런트엔드 구조 변경입니다. 기존 서버 함수·푸시 설정을 재배포하거나 기존 알림 예약·공간 권한을 변경하지 않았습니다. 투자 원문 수정의 양방향 동기화, 알림의 실기기 전달 보장은 이번 변경 범위가 아닙니다.

## 구조와 디자인

`src/core/calendar-scope.js`는 현재 분류와 이전 기록 보존 규칙, `src/core/feed-connection.js`는 선택 데이터 연결의 갱신·실패 격리, `src/modules/`는 독립 입력 모듈을 담당합니다. 상세 계약은 [ARCHITECTURE.md](ARCHITECTURE.md)에 있습니다.

펄 화이트·연핑크·블루·세이지 민트 테마를 유지합니다. `theme.css`는 별도 디자인 파일이며 저장된 사용자 지정 색은 덮어쓰지 않습니다. 배포 정보는 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요.
