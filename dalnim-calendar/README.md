# 달님 캘린더 0.1

기존 디자인 기준(밝은 화면·파란 주요 행동·의미 있는 색·점진적 상세)을 반영한 독립 캘린더 첫 버전입니다.

## 지금 사용 가능

- PC 주간 시간표, 일간·월간·연간·목록 보기.
- 일정 추가·수정·드래그 이동·길이 변경·삭제·휴지통 복원.
- 매일·매주·매월·매년 반복(전체 반복 수정).
- 검색, 분류 표시, 분류 추가·이름·색상 변경.
- 워크로그·투자·가족 상세 블록 켜기/끄기. 꺼도 기록 유지.
- 워크로그 JSON 가져오기, 일정 JSON 백업, 인쇄.
- 모바일 일간 화면과 홈 화면 설치 기반.
- 로컬 체험은 IndexedDB 저장, 동시 탭 수정 충돌 검사.

화면의 일정은 실제 업무·시장 발표가 아닌 예시입니다. ‘예시 지우기’를 누르면 직접 만든 일정은 유지됩니다.

## 실행

Node.js 22 이상에서 이 폴더의 터미널을 열고:

    npm start

http://127.0.0.1:4173 을 엽니다. 프런트엔드 미리보기에는 npm install이 필요하지 않습니다. HTML을 더블클릭(file://)하면 ES 모듈과 저장소 제약으로 정상 실행되지 않습니다.

GitHub Pages에 이 폴더를 올리면 /dalnim-calendar/ 경로에서 체험할 수 있습니다. 공개 웹 파일과 사용자 데이터 공개는 별개이며, 실사용 전 클라우드 인증과 보안 규칙을 설정해야 합니다.

다른 페이지에 삽입:

    <iframe src="./dalnim-calendar/?embed=1" title="달님 캘린더" style="width:100%;height:850px;border:0"></iframe>

## 아직 활성화되지 않은 것

- 클라우드 배포·가족 계정 로그인·다기기 공유: 서버 코드 포함, 배포·계정 설정 필요.
- 휴대폰 실제 푸시: 서버 코드 포함, 키·기기 등록·실기기 검증 필요.
- 기존 워크로그와 완전한 양방향 연동: 현재 JSON 가져오기만 구현.
- 실시간 투자 데이터 수집, 반복 일정의 개별 발생 수정, 첨부파일 업로드.
- 읽음 회신·미확인 재알림·문자 대체 발송.
- 클라우드 모드의 오프라인 수정 큐. 연결이 끊긴 저장은 오류로 표시합니다.
- 다른 시간대로 여행할 때 반복 시간 유지의 브라우저/서버 일치 검증. 초기 실사용 시간대는 Asia/Seoul을 권장합니다.

체험 공간에서는 알림 시간을 저장해도 실제 알림이 발송되지 않습니다. 컴퓨터가 꺼졌을 때도 동작하는 것은 DEPLOYMENT.md의 클라우드 배포 이후입니다.

## 파일 안내

ARCHITECTURE.md — 모듈 경계, 이벤트·저장·연결 계약
DEPLOYMENT.md — Firebase 테스트 공간 배포와 활성화 절차
server/ — 인증 API와 예약 푸시 함수
src/modules/ — 선택 기능 블록
src/adapters/ — 기존 앱 연결 어댑터

설치 후 npm test로 도메인·권한 검사를 실행합니다. 로컬 날짜·반복·블록 격리·권한 검사 외에 브라우저 조작 검수도 수행했습니다. 실제 서비스 배포를 끝낸 제품으로 오인하지 않도록 앱에 체험 상태를 명시했습니다.
