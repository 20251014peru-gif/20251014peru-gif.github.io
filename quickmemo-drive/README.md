# 순간메모 · Google Drive

프로그램 코드만 이 폴더에 저장합니다. 메모·사진은 로그인한 사용자의 Google Drive와 기기 IndexedDB에 저장합니다.

접속 예정 주소: https://20251014peru-gif.github.io/quickmemo-drive/

Google OAuth 클라이언트의 승인된 JavaScript 원본에 `https://20251014peru-gif.github.io`를 등록해야 합니다. 경로 `/quickmemo-drive/`는 원본 설정에 넣지 않습니다.

앱이 열려 있는 동안 저장 후·화면 복귀·60초 주기로 동기화합니다. 접근 토큰은 메모리에만 보관하므로 다시 열거나 만료되면 Google Drive 연결 버튼으로 다시 승인하세요. 첫 연결 계정과 다른 계정의 연결은 차단합니다. 다른 계정은 별도 브라우저 프로필을 사용하세요.

동시 수정본은 별도 기록으로 보존합니다. 사진은 내용 해시로 중복 업로드를 막습니다. 휴지통 변경은 전달하며 클라우드 이력은 자동 삭제하지 않습니다. 저장 한도는 Drive/Gmail/Photos 공유 용량입니다.

모의 검증: 두 기기 전송, 오프라인 후 재시도, 동시 수정 보존, 사진 복구·중복 방지, 휴지통 전달, 계정 혼합 차단 통과. 실제 Google 로그인·휴대폰·오프라인 재접속 검증은 별도 수행해야 합니다.

기존 Firebase 프로젝트의 데이터와 보안 규칙은 사용하거나 변경하지 않습니다.
