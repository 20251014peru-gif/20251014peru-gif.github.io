# MACRO_STANDARD v1 — 미국·한국 매크로 감각 표준

> 상태: Draft v1 / 지표·출처·판정 규칙 확정 중
>
> 목적: 미국과 한국의 매크로 환경을 동일한 구조로 관찰하되, 각 국가의 경제구조 차이를 반영하여 투자에 필요한 방향·변화·자금환경을 표준화한다.

## 1. 공통 관찰 축

모든 국가를 최소 다음 축으로 본다.

1. 성장
2. 물가
3. 고용
4. 통화정책
5. 금융조건·유동성
6. 시장가격 확인
7. 자금흐름
8. 대외환경

국가별 핵심지표는 다를 수 있으나 출력 구조는 동일하게 유지한다.

## 4. 지표별 표준 필드

각 지표는 최소 다음을 관리한다.

- `indicator_id`
- `country`
- `category`
- `name`
- `importance`: core / confirm / early / lagging / watch
- `frequency`
- `release_time_rule`
- `official_source`
- `series_id_or_endpoint`
- `previous`
- `consensus`
- `actual`
- `surprise`
- `direction`
- `acceleration`
- `growth_effect`
- `inflation_effect`
- `policy_effect`
- `market_relevance`
- `data_status`

## 5. 해석 원칙

현재값 하나로 좋음/나쁨을 단정하지 않는다.

각 지표는 가능한 한 다음을 분리한다.

- 수준(Level)
- 방향(Direction)
- 변화속도(Velocity)
- 가속/둔화(Acceleration)
- 예상 대비 Surprise
- 추세 지속기간
- 시장 반응

예: PMI가 확장영역에 있어도 직전보다 둔화되면 `수준=확장`, `방향=하락`, `속도=둔화`처럼 동시에 표현한다.

## 6. 미국↔한국 상대시장 판정용 공통축

미국과 한국을 매일 다음 축으로 비교한다.

- 성장 모멘텀
- 물가 부담
- 통화정책 방향
- 금융조건
- 기업이익 방향
- 밸류에이션 후보
- 실제 자금흐름
- 통화 방향
- 시장 내부 상대강도
- 외부환경 민감도

초기 버전에서는 임의의 종합점수를 만들지 않는다. 각 축의 관찰과 상대우위 근거를 저장하고, 실제 결과가 쌓인 뒤 평가 프로토콜로 가중치를 정한다.

## 7. 투자용 출력

매크로 감각은 단순 지표판이 아니라 다음 질문에 답해야 한다.

- 성장은 가속/둔화 중인가?
- 물가는 가속/둔화 중인가?
- 고용은 강화/약화 중인가?
- 금융조건은 완화/긴축 중인가?
- 미국과 한국 중 어느 쪽이 상대적으로 우호적인가?
- 실제 시장과 자금흐름이 매크로 해석을 확인하는가?
- 어떤 산업/스타일이 유리하거나 불리한가?
- 다음 확인해야 할 지표/이벤트는 무엇인가?

## 8. AI 독립성

핵심 판정은 공식 데이터, 시장데이터, 계산규칙으로 가능해야 한다.

AI는 선택적으로:
- 긴 문서/발표문 의미 추출
- 지표 간 관계 후보 제시
- 사람이 읽기 쉬운 설명

에 사용한다. AI가 없어도 매크로 감각은 작동한다.
